# 🌤️ WeatherApp

> A modern, dynamic web application that allows users to search for any city globally and instantly retrieve comprehensive, real-time weather information.

## 📌 About The Project
WeatherApp is an intuitive tool built to solve the daily problem of checking atmospheric conditions. The project focuses heavily on interacting with REST APIs, parsing JSON data, and updating the user interface dynamically based on live global metrics. It serves as an excellent demonstration of JavaScript and clean UI design.

## 🛠️ Tech Stack
*   **Core:** HTML5, CSS3, JavaScript (ES6+)
*   **API Integration:** Fetch API / Axios (Interacting with OpenWeatherMap)
*   **Styling:** Responsive Web Design (Flexbox, CSS Grid, Media Queries)

## 🌟 Key Features
*   🔍 **Global Search:** Instant lookup for weather data by typing any city name.
*   🌡️ **Comprehensive Weather Metrics:** Displays current temperature, "feels like" temperature, humidity levels, wind speed, and atmospheric pressure.
